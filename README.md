# St. Agnes Academy of Caloocan — Alumni Management System

A web-based Alumni Management System for St. Agnes Academy of Caloocan.

## Project layout

| Path              | Description                                                    |
| ----------------- | -------------------------------------------------------------- |
| `index.html`      | Main single-page application (home, login, dashboard, directory, events, QR-code verification) |
| `style.css`       | Custom design system / brand styling                           |
| `logo.jpeg`       | School logo asset                                              |
| `alumni-system/`  | React + Vite front-end app (work in progress)                  |

## Quick start — static app

No build step required. Open `index.html` in any modern browser.

The page loads the following resources from CDNs:

- Tailwind CSS
- Chart.js
- QRCode.js
- Font Awesome
- Google Fonts

## Alumni System app (React + Vite)

```bash
cd alumni-system
npm install
npm run dev        # start the dev server
npm run build      # production build
npm run preview    # preview the production build
```
